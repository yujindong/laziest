# @laziest/logger

## 0.2.0

### Minor Changes

- Introduce `@laziest/logger`, a TypeScript logger package with typed levels, safe serialization, formatter presets, and pluggable transports.

  This release includes:

  - package scaffolding, tsdown build output, and Vitest coverage
  - typed log levels and public logger contracts
  - safe serialization for errors, getters, proxies, and unknown values
  - compact, JSON, and pretty formatter presets
  - console and memory transports
  - core logger APIs with child context, metadata, formatter, and transport support
  - usage documentation for installing and configuring the package
